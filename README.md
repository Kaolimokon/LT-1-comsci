# LT-1-comsci
#Numerical Notebook Evaluator

##Function
Calculates the ratio and proportions of how every box holds the same number of notebooks, and how any notebooks that do not fill a whole box are sent in a separate loose pack.

##Data input (SECTION 1) 
Input the total number of notebooks and how many notebooks can fit inside a single box.

##Data reiteration (SECTION 2)
This part will reiterate the data for the next step.

##calculation (SECTION 3)
This part will calculate needed values based on the data given.

##Full boxes vs Loose packs (SECTION 4)
This part will say how many full boxes there are and how many loose packs, too.

##Loose book conclusion (SECTION 5)
This part will conclude if there was no full box filled, and consequently loose books will go to the loose pack.
